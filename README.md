# 🎬 Movies

Aplicación desarrollada para la gestión y consulta de películas, con una interfaz web construida principalmente con **Angular** y una aplicación móvil desarrollada utilizando **Ionic**.

## 🚀 Tecnologías utilizadas

### 🅰️ Angular

**Angular** es la tecnología principal utilizada para el desarrollo de la aplicación web.

El proyecto utiliza Angular para:

* Construcción de la interfaz de usuario.
* Organización de la aplicación mediante componentes.
* Manejo de rutas y navegación.
* Desarrollo de páginas y funcionalidades.
* Implementación de servicios.
* Gestión de la lógica de la aplicación.
* Desarrollo utilizando **TypeScript**.

### 📱 Ionic

Se utilizó **Ionic Framework** para el desarrollo de la aplicación móvil, permitiendo reutilizar la estructura y lógica desarrollada con Angular y adaptar la aplicación a dispositivos móviles.

La aplicación utiliza componentes de Ionic para:

* Construcción de interfaces móviles.
* Navegación entre las diferentes vistas.
* Diseño adaptable a dispositivos móviles.
* Desarrollo de una experiencia de usuario orientada a aplicaciones móviles.

Además, el proyecto utiliza **Capacitor** como parte del entorno para aplicaciones móviles.

## 🛠️ Tecnologías y herramientas

* **Angular** – Framework principal para el desarrollo web.
* **Ionic Framework** – Desarrollo de la aplicación móvil.
* **Capacitor** – Integración y soporte para aplicaciones móviles.
* **TypeScript** – Lenguaje principal utilizado en Angular.

* **SCSS** – Estilos y diseño visual.

## 💻 Ejecución del proyecto

Para ejecutar el proyecto localmente es necesario tener instalado **Node.js**, Angular CLI e Ionic CLI.

### Instalar dependencias

Desde la carpeta del proyecto:

```bash
npm install
```

### Ejecutar con Angular

Para iniciar la aplicación utilizando el servidor de desarrollo de Angular:

```bash
ng serve
```

La aplicación estará disponible normalmente en:

```text
http://localhost:4200
```

### Ejecutar con Ionic

Para ejecutar la aplicación mediante Ionic:

```bash
ionic serve
```

La aplicación estará disponible normalmente en:

```text
http://localhost:8100
```

## 📱 Aplicación móvil

El proyecto incorpora **Ionic + Angular + Capacitor** para el desarrollo de la aplicación móvil.

Esta integración permite utilizar tecnologías web para construir una aplicación orientada a dispositivos móviles y posteriormente realizar su integración con plataformas móviles compatibles mediante Capacitor.
